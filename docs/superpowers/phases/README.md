# Phases

Each development phase (spec `docs/superpowers/specs/2026-07-24-dev-workflow-phase-cycle.md`) gets a directory `phase-<n>/` containing its `tasks.md` task graph. The phase's spec lives at `docs/superpowers/specs/YYYY-MM-DD-phase-<n>.md`.

- **Templates:** `docs/superpowers/templates/` — `phase-spec-template.md`, `tasks-template.md`, `builder-brief-template.md`.
- **Standing fleet reference:** `docs/process/coordination.md`.

No phase exists yet: the cycle starts with the first design session after epic #335 reaches the MVP bar (spec §9). Phase 1 is whatever that session scopes.
