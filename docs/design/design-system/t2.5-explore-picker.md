# T2.5 — W-1 Explore picker wireframe record

Status: **drawn proposal awaiting reviewer validation and Rob's ruling**. This record and
`t2.5-explore-picker.html` are one artifact. The PNGs are deterministic captures of the HTML at
the variants named below.

## Constraint structure — enumerated before figures

1. **Discovery scope is one persisted state set:** visible categories, include-hidden,
   show-saved, and coverage shading. Its default is all categories visible, hidden OFF, saved ON,
   coverage ON (P2R-5).
2. **List-map filtering is a different state set:** `TracksVisitFilter` narrows visits in an
   active list map by loved state, cross-list membership, and category. It is not silently
   re-labelled as discovery scope (OF4).
3. **The category grid is the shared control seam:** in an active list map,
   `ListMapLayerVisibility.displayed/updating` already maps the grid to the list visit filter's
   category set. Category controls are not duplicated.
4. **All state edits are live, reversible, and immediately legible in their owning domain.**
   List controls affect the current Tracks-mode list map. Discovery-default edits persist and
   report their new state immediately, but P2R-8 forbids them from thinning the active list story.
   There is no grouped-edit mode and no filled Apply action. The sanctioned grouped-edit fallback
   remains available only if validation finds the drawn flow mis-tappy.
5. **Clear scope is one quiet verb:** when any effective map-scope state is non-default, it resets
   the four persisted discovery choices and, in list-map context, the active list visit filter.
   It is absent when there is nothing to clear. This makes the one-tap exit truthful in every
   state that can thin the current map.
6. **The Explore door's indicator follows effective scope:** the exact proposed predicate reads
   unbridged discovery `layerVisibility` and is
   `layerVisibility.scopeDiffersFromDefault || (activeListMap.showVisited &&
   activeListMap.visitFilter.isActive)`. A stored list filter is dormant in Fresh mode and does
   not activate the indicator or Clear by itself. The visible text `Scope set` and accessibility
   value `Scope adjusted` make active state non-colour-only.
7. **OF5 proposal for Rob — retain switch morphology for Scope rows:** P2R-4 ratified the A8
   switch-row geometry wholesale for this row class, but geometry ratification alone does not
   settle morphology. This proposal keeps switches because knob position and track shape report
   ON/OFF without colour, while R15's filled-pill + filled-glyph morphology is applied to every
   state chip. Rob's ruling must explicitly accept or reject this switch-row exception.
8. **Search renders nothing.** Settings and About remain navigational quiet rows with full
   44pt targets. The Scope chips are reversible state controls and may use R10 tiling.
9. **The surface states under review are complete as a set:** door/default, door/scope-set,
   door/scope-set-AX; picker/default, picker/adjusted, picker/list-context, picker/AX; and the
   Other-lists child in populated, empty, and AX stress states. The default frame pins the ruled
   order and defaults; the other frames prove the indicator, Clear-scope exit, OF4 answer,
   bounded user-sized data, and Dynamic Type behavior.

## OF4 — list-mode merge answer

Three approaches were considered:

1. **Contextual merge (drawn):** in list context, visibly separate `This list map` from
   `Discovery map defaults`. The existing bridge makes the shared category grid list-sensitive;
   Loved stays inline under `Visits in this list`; cross-list membership moves through one
   full-target `Other lists` drill-in in the same Explore navigation stack. This preserves the
   two state models without leaving a second Scope entry point.
2. **One undifferentiated chip field:** mix discovery, loved, list-membership, and category state
   under one label. Rejected because it hides which domain a control changes.
3. **Keep the floating list chips:** rejected because #469 explicitly requires one Scope surface
   and the overlay would remain a second entry point.

The active list itself is context, not a redundant filter chip. Category choices use the main
category grid. Cross-list membership is user-sized and therefore is not rendered as an unbounded
inline chip collection: the `Other lists` row reports a selected-count summary and opens a
scrolling in-picker child whose per-list state chips update live. That child keeps Clear scope
outside its scrolling collection and retains the same full-width exit when it returns. The old
standalone filter sheet's Apply/Close controls retire and P2R-7 remains true.

Eligible membership choices are saved, non-system lists excluding the active list. They sort by
case-insensitive display title with stable identifier as the tie-break. The parent summary is
`None selected`, the selected title when exactly one is active, or `<first title> · N selected`
for two or more. The child root and Back control are fixed; the collection scrolls independently.
Its empty state names that the active and system lists are excluded and renders no inert state
capsules. If any other scope dimension is non-default, Clear remains present outside the empty
collection.

In list context the discovery rows say they apply after leaving the list and never filter its
story. Clear scope resets both the effective Tracks-mode list filter and the four discovery
defaults. In Fresh mode a retained list filter is dormant: Clear and the door indicator follow
only the discovery predicate until Tracks mode makes that list filter effective again. Editing
Loved, category, or membership state while Fresh is visible promotes the list map to Tracks so
the live change is effective immediately.

## Identifier annex — A1 convention

The convention is `explore.scope.<control>`, matching the landed
`explore.row.settings` / `explore.row.about` ownership boundary. T2.8 performs this contract
rename once, in one commit, with nothing else in flight.

| Current contract | W-1 target contract | Disposition |
|---|---|---|
| `map.layers` | — | Retired A1 launcher; no replacement identifier. Preserve the negative regression by asserting no `Layers` button label, then prove `map.door.explore` opens `explore.root`. |
| `map.layers.show-hidden` | `explore.scope.include-hidden` | Relocated Scope switch row. |
| `map.layers.show-saved` | `explore.scope.show-saved` | Relocated Scope switch row. |
| `map.layers.coverage-shading` | `explore.scope.coverage-shading` | Relocated Scope switch row. |
| `map.layers.show-all-categories` | `explore.scope.categories.toggle-all` | Relocated quiet category verb. |
| `map.layers.category.<id>` | `explore.scope.category.<id>` | Relocated category state chip. |
| — | `explore.scope.clear` | New P2R-5 quiet Clear-scope row. |
| `map.list-mode.filter.loved` and `track-filter-picker.loved` | `explore.scope.list-visits.loved` | One contextual state chip replaces both entry points. |
| `track-filter-picker.list.<id>` | `explore.scope.list-visits.list.<id>` | Cross-list membership state chip inside the bounded `Other lists` child. |
| `map.list-mode.filter.category.<id>` and `track-filter-picker.category.<id>` | `explore.scope.category.<id>` | Folded through the existing category bridge; no duplicate control. |
| `map.list-mode.filter.lists` | `explore.scope.list-visits.lists` | Full-target `Other lists` drill-in inside Explore replaces the floating aggregate launcher. |
| — | `explore.scope.list-visits.lists.root` | New bounded child root. |
| — | `explore.scope.list-visits.lists.back` | New full-target return to the parent Scope state. |
| — | `explore.scope.list-visits.lists.empty` | New empty-state contract when no eligible list exists. |
| `track-filter-picker.category.all` | `explore.scope.categories.toggle-all` | The shared category verb is the replacement. |
| `track-filter-picker.apply`, `track-filter-picker.close`, `track-filter-picker.sheet` | — | Grouped-edit sheet retires; state updates are live. |

The Explore door keeps `map.door.explore`; its accessibility value becomes `Default scope` or
`Scope adjusted`. Settings and About keep `explore.row.settings` and `explore.row.about`.

T2.8 re-points rather than deletes behavior coverage. Its predicate matrix covers default versus
non-default discovery scope, Tracks versus Fresh mode with a retained active list filter,
coverage OFF, and a non-default discovery category while a list map is active. A P2R-8 test
proves that changing `Show saved places` persists discovery state without removing list-story
rows. Chip tests assert ON filled glyph / OFF outline glyph independently of VoiceOver values.
