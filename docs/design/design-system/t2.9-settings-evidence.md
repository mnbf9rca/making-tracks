## Regeneration

Run from the repository root. The script refuses to run without the simulator lock or under a different Xcode version, performs the focused release gate, validates both image dimensions, and prints their SHA-256 digests.

```bash
MT_RELEASE_GATE_DESTINATION='platform=iOS Simulator,id=BACC2CF8-C1F8-4C92-B058-47B0AC0B128D' \
  ./scripts/sim-lock.sh ./docs/design/design-system/regenerate-t2.9-settings.sh
```
