The `before` fixture is a faithful in-tree reference of the exact base leaf—17pt
`.headline.weight(.medium)`, monochrome, fixed 28pt column—because the shared wrappers have no
current production instantiation to navigate to on the exact base. The `after` fixture mounts the
real `MapDoorRowIconColumn` and `MapDoorRowIconGlyph`. This limitation is explicit: the before PNG
is not an exact-base app binary; it is the exact-base code path rendered beside the candidate by a
single deterministic harness. The original live Explore base/head captures independently exposed
the Site 3 AX collision that led to the scaled-column repair.

## Measured render delta

All dimensions below are rendered bounding boxes in points for `cloud.sun.rain.fill` on the pinned
simulator/toolchain. The column figures come from the real SwiftUI component; the in-row image
figures and separation constraints come from the UI accessibility frames used for these captures.

| State | Legacy 17pt glyph | `rowRaised` glyph / column | `rowQuiet` glyph / column | In-row glyph-to-copy gap |
|---|---:|---:|---:|---:|
| Default | 25×26 | 30×32 / 32×32 | 27×30 / 28×30 | at least 11.9 |
| AX5 | 77×85 | 81×89 / 90×89 | 76×83 / 81×83 | before: negative; after: at least 11.9 |

The material-row UI frames additionally pin 79.7pt for both legacy AX glyphs, 84.7pt for the
semantic raised AX glyph, and 78.7pt for the semantic quiet AX glyph. The difference from the
standalone renderer is the real material control environment; both measurements are executable
test oracles. The legacy AX frame proves teeth by requiring overlap, while the after frame requires
both glyph/copy pairs to remain contained with the ruled 12pt spacing within floating-point
tolerance.

The live Explore quiet destination uses `gearshape`: its default glyph/column is 24×24 / 24×24;
at AX5 it is 66×66 / 70×66. That 4pt AX clearance is pinned. The first post-migration runtime
capture had kept the column at 24pt and visibly collided with the subtitle.

## Contract and scope

- Raised shared door rows migrate from the 17pt headline literal to `IconRole.rowRaised`: 20pt
  relative to `.headline` through `TypographyRole.listRowTitle`, with a 32pt base column that
  scales on the same anchor.
- Hairline shared door rows migrate to `IconRole.rowQuiet`: 18pt relative to `.subheadline`
  through `TypographyRole.button`, with a 28pt base column that scales on that anchor.
- Explore quiet destinations migrate from an 18pt body anchor to `rowQuiet`, retain a local
  `.fontWeight(.medium)` override, and scale their 24pt base column relative to `.subheadline`.
  The override deliberately preserves shipped no-pulse behavior.
- `ExploreSurfaceIconGeometry.scopeControl`, `ExploreScopeControlGlyph`, its body anchor, and all
  `map.layers.*` identifiers are unchanged. Scope/site 2 belongs to T2.8.

The first AX repair was confined to the owned row because A8's frozen AX frame is clean. The
scrollable root, row order, copy, chevrons, navigation, and button morphology remain unchanged.

## Verification and adversarial review

- Initial TDD RED: the focused Explore column test failed to build because
  `ExploreQuietDestinationIconColumn` did not exist.
- Reviewer-driven measurement RED: the raised AX glyph measured 81pt against an insufficient
  79pt scaled column; the raised base was corrected from 28pt to 32pt.
- Focused role/measurement regressions: 4 tests, 0 failures in 0.137 seconds.
- Mutation proof: hard-coding `.rowRaised` through the quiet column and bypassing the Explore glyph
  produced 4 failures across the 2 point-of-use tests; restoring the committed implementation
  removed the mutations byte-for-byte.
- Earlier live Explore AX regression: 1 test, 0 failures in 30.225 seconds.
- Exact-head host Swift suite: 514 tests, 0 failures in 9.980 seconds. Full simulator gate counts
  are recorded in the PR verification ledger.

Three independent reviewers challenged correctness/identifiers, interaction/accessibility, and
spec/evidence. Their surviving findings were: false-green forwarding seams, underspecified AX
width coverage, an unscaled shared-row column, screenshots that omitted the primary shared-row
migration, and missing regeneration/measurement provenance. The implementation, tests, harness,
script, and this packet incorporate all five. No untrusted-data, privacy, network, persistence,
parsing, or other security boundary changed.
