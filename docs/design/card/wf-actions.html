Two edges the diagram deliberately omits, and what they mean on the card.
No Loved → Unseen. Slot 3 is disabled in the Loved state. Un-seeing a loved place is two deliberate steps: unlove, then un-see. You cannot discard the stronger record in one tap.
No Hide → Seen. Unhiding returns a place to Unseen, never straight to Seen. Hiding is not a way to record having been somewhere.
What this settles. The slot count is constant at three, so the row never re-flows under the user's thumb and there is no empty cell to reserve. Hide stays one tap. Add to list is the only action outside the ruled set and keeps its overflow home; the list chips already open the picker.
Terminology, resolved. There is one ladder — Unseen ⇄ Seen ⇄ Loved — with Hide as a side branch off Unseen. There is no separate "visited" state distinct from "seen".
