Three consequences.
1 · The reserved-slot problem disappears. An earlier draft proposed reserving an empty cell for Love so the row would not re-flow under the user's thumb between finger-down and the database write returning. With a fixed three slots there is nothing to reserve — the slot is stable and only its label changes.
2 · The two-tap Hide proposal is rejected. An earlier draft moved Hide behind an overflow menu to fit five buttons. Three slots fit comfortably, so Hide stays one tap.
3 · Add to list keeps its overflow home. It is the only action not in the ruled set, and the list chips already open the list picker.
